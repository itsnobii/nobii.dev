by nobii
Welcome! The VCT 2025 overlay is available on this domain.
To use the overlay, you need to enter the correct URL with your group code.
Please use one of the following formats:
https://vct25.nobii.dev/agent-select?groupCode=[YOUR GROUP CODE]
https://vct25.nobii.dev/overlay?groupCode=[YOUR GROUP CODE]
Replace [YOUR GROUP CODE] with the code you set in the Spectra Client.
If you need more help, join the Discord Server.
